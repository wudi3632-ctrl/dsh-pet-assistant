# 故障排查

先运行：

```powershell
.\scripts\doctor-windows.ps1
```

## 一直“正在听”或完全听不到

确认 Windows 麦克风权限、默认输入设备和远控虚拟输入；在系统录音测试中先确认电平。切换设备或设置环境变量后彻底退出并重启 DSH。扬声器回录会使 VAD 一直有声，优先戴耳机并关闭“侦听此设备”。

## 唤醒词无反应

检查 KWS 模型四个文件和 `keywords-dsh-pet.txt` 是否位于 `DSH_PET_ASR_MODEL` 根目录；确认文件是 UTF-8 且没有 `.txt.txt` 后缀。先用正常音量清晰说完整“大肥鱼”。

## 能唤醒但识别错误

检查 Paraformer 的 `tokens.txt`、encoder 和 decoder；让麦克风保持 16 kHz 友好输入，降低远控压缩和系统回声。专有软件名可在上层指令解析做同音纠错，但不要用白名单代替通用软件发现。

## TTS 慢或没有声音

```powershell
Invoke-RestMethod http://127.0.0.1:9883/health
```

确认 GPU 服务已预热、模型没有每句重新加载。检查 `DSH_PET_QWEN_SERVICE` 指向真实脚本。首次下载模型会明显变慢；模型应放在本地 SSD，避免 Qwen 与 CosyVoice 同时抢显存。

## 气泡与声音不同步

确认运行的是本仓库部署后的 `lib` 和 `runtime/electron-helper`，而不是旧插件副本。退出 DSH、重新部署并重启。长回复应分句流式展示，气泡会在一段时间后收起。

## 软件说“未安装”

软件发现会尝试已有窗口、开始菜单/注册信息和通用 UI 操作。便携软件若没有快捷方式或注册信息，建议创建开始菜单快捷方式。已经登录的软件应优先激活现有窗口，而不是再启动实例。

## 鼠标点到桌宠自己

自动化执行期间桌宠窗口应临时不抢点击，并与目标坐标保持偏移。若仍发生，确认 helper 已更新并重启 DSH；多屏缩放不一致时把各显示器缩放暂时统一进行验证。

## Windows 操作没有执行

必须处于未锁屏的交互式桌面。普通权限进程不能可靠控制管理员权限窗口，UAC 安全桌面也不可自动化。远程桌面断开后 Windows 可能冻结桌面；保持会话活动或使用不会锁定会话的远控方式。

## 回滚部署

`deploy-local.mjs` 会输出备份目录。退出 DSH，把时间戳目录里的 `lib`、`runtime/electron-helper` 和 `assets/config.jsonc` 复制回插件目录，再启动 DSH。
